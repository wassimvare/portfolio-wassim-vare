PORTFOLIO WASSIM VARE — V2

La refonte est préparée sur la branche refonte/portfolio-v2.

Pour prévisualiser depuis la racine du dépôt, lancer la commande suivante.
  python3 -m http.server 8000 --bind 127.0.0.1

Puis ouvrir http://127.0.0.1:8000/iPortfolio/ dans le navigateur.

Après validation des modifications, pousser la branche et ouvrir une pull
request vers la branche utilisée par GitHub Pages. Publier après revue
en fusionnant la pull request. Conserver la source et les réglages Pages
existants ainsi que le dossier iPortfolio/.
